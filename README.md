A program that writes a deadpan one-star review of gravity to
`/output/entry.txt`, for the make.fun competition
[One-Star Review of Something Essential](https://make.fun/bounty/u-0xb3e689-one-star-review-of-something-essential-c7234629).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`) and prints it. No network, no clock,
no randomness. The entry is 111 characters, inside the 1 to 160 gate.

## The entry

```
One star for gravity. It never takes a day off, never calls in sick, and still drops my toast butter side down.
```
